
This is an app that will give the user directions to a specific destination either through text or a picture. The user can either use the camera or an uploaded picture to get directions to their destination. They will also have the option to use text for their destination in a seperate tab. The app will need the CLLocation feature. It will also include a map to show the users location. In addition, there will be an option to save their directions to a public repository on icloud.developer.apple.com.  This app will also be able to give directions to a specific place while they are inside a building.
